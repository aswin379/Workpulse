# User Manual Synchronization Rule

Whenever features, UI workflows, forms, navigation items, buttons, or state logic are added, modified, or removed across the application:
1. Automatically update [USER_MANUAL.md](file:///e:/shaminew/USER_MANUAL.md) in the same turn to reflect the changes.
2. Ensure descriptions, form fields, action steps, screenshots/references, and workflows in `USER_MANUAL.md` remain completely accurate and up-to-date.
3. Do NOT wait for explicit user reminders or requests to update the manual—update it proactively upon every implementation or feature change.
